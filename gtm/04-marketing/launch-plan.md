# Launch Plan (Phased)

> "Launch" here = a controlled, staged go-live, not a big public splash. De-risk first, scale on proof.

## Phase 0 — Readiness (pre-launch gate)
**Must be true before selling to real providers handling patient data:**
- [ ] **Auth/security hardened** (passwords, real session identity) — see capabilities gaps.
- [ ] Functionality + integration audits passed (the upcoming audits).
- [ ] Hosting/deployment model decided (managed SaaS vs on-prem).
- [ ] Onboarding/data-migration playbook drafted.
- [ ] Pricing model decided (internally) + owner sign-off path.
- [ ] Legal/data basics checked `[RESEARCH NEEDED]`.

## Phase 1 — Private pilots (design partners)
- Recruit 3–5 friendly providers (1–2 per segment).
- Free/low-cost, time-boxed, with explicit success metrics.
- Goal: prove ROI, harden the product, generate first references.

## Phase 2 — Beachhead sell
- Turn pilot wins into case studies.
- Run direct + referral + partnership channels (channels-plan).
- Goal: first paying customers, repeatable onboarding, validated price.

## Phase 3 — Expand
- Upsell modules/locations; sell suite to mid-size hospitals.
- Scale content + (later) paid channels once economics are proven.

## Phase 4 — Upmarket
- Diagnostic / multi-specialty chains; multi-location + integrations.

## Launch metrics (set real targets after Phase 1)
- Pilots live · pilot→paid % · first ARR · references · onboarding time · CAC/payback.

## Risks & mitigations
- **Security/trust** → harden auth + be honest; lead with pilots.
- **Adoption** → role-simple UX + training; design-partner feedback.
- **Connectivity** → assess offline tolerance `[confirm]`.
- **Cash/runway** → keep beachhead lean, founder-led.
