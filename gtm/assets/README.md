# Assets

Binary / design assets for GTM live here: logos, pitch deck, product one-pagers, demo videos, case-study PDFs.

## Suggested structure
- `logo/` — logo + brand marks (once brand name is decided)
- `deck/` — pitch deck (if raising) and sales deck
- `one-pagers/` — per-segment one-pagers (clinic, pharmacy/lab, hospital)
- `videos/` — demo recordings per workflow
- `case-studies/` — finished case-study PDFs (real pilots only)

> Keep large binaries out of git history where possible. Nothing fabricated — case studies use real pilot data only.
