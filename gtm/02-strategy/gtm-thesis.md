# GTM Thesis — One Page

**The bet:** Small and mid-size healthcare providers in Pakistan/South Asia are stuck on paper + disconnected point tools. An integrated, regionally-priced HMS that makes pharmacy/billing ROI obvious on day one can land fast, then expand into running the whole provider.

## North star
Become the default operating system for SMB private healthcare providers in the region — starting where the ROI is fastest (pharmacy/billing/clinic ops), expanding to the full hospital suite.

## Strategy in one line
**Wedge-and-expand:** land with the cheap, ROI-obvious module (pharmacy/lab/clinic), expand to the integrated suite, then move upmarket to chains.

## Who (sequenced)
1. Small clinics / single-doctor practices
2. Standalone pharmacies / labs
3. Mid-size private hospitals
4. Diagnostic / multi-specialty chains

## Why we win
1. **Integration** — clinical + pharmacy + lab + billing + HR on one database (data can't drift).
2. **Database-enforced integrity** — stock/money/visit-state correctness built into the DB, not bolted on.
3. **Price + fit for emerging markets** — built for cost-sensitive providers, unlike enterprise EHRs.
4. **Consolidation** — replaces 3–4 vendors with one system + one support line.

## How we go to market
- **Motion:** founder-led, high-touch sales + referrals in the beachhead; productized onboarding.
- **Proof:** pilot → ROI case study → referral loop.
- **Channels:** direct outreach, provider networks/associations, pharmacy/medical-supplier partnerships, content. (See [../04-marketing/channels-plan.md](../04-marketing/channels-plan.md).)

## What has to be true (and must be validated)
- Providers will pay (model + price point) — `[RESEARCH NEEDED]`
- Pharmacy/billing ROI is the sharpest wedge — validate in discovery.
- We can onboard/migrate without painful downtime.
- **Auth & data security are hardened** before real patient data is handled.

## 12-month success markers (set real targets after pricing/CAC work)
- N pilot deployments live · first paid customers · 1–2 reference case studies · repeatable onboarding · validated price point.
